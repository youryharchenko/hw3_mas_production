### MCP Tools (Інструменти)

Інструменти призначені для виконання динамічних символьних та числових обчислень через бібліотеку SymPy. Усі інструменти обробляють винятки та повертають об'єкт із прапорцем `success`, результатом у форматі рядка SymPy, кодом LaTeX та описом помилки у разі невдачі.

* **`compute_limit`**
 
**Опис:** Обчислює односторонні та двосторонні границі математичних функцій (Limit).

**Параметри:** `expression` (вираз), `variable` (змінна, за замовчуванням `"x"`), `point` (точка наближення, за замовчуванням `"0"`, підтримує `"oo"`, `"-oo"`), `dir` (напрямок: `"+-"`, `"+"`, `"-"`).


* **`compute_derivative`**

**Опис:** Знаходить похідні першого та вищих порядків для заданого виразу (Derivative / Differentiation).

**Параметри:** `expression` (вираз), `variable` (змінна, за замовчуванням `"x"`), `order` (порядок похідної, ціле число $\ge 1$).


* **`compute_indefinite_integral`**

**Опис:** Обчислює невизначений інтеграл (первісну функцію) без врахування константи інтегрування $C$ (Indefinite Integral /
Antiderivative).

**Параметри:** `expression` (вираз), `variable` (змінна інтегрування, за замовчуванням `"x"`).


* **`compute_definite_integral`**
 
**Опис:** Обчислює визначений інтеграл на заданому проміжку (Definite Integral). Крім символьного аналітичного результату, намагається додатково розрахувати наближене числове значення (`numeric_value`).

**Параметри:** `expression` (вираз), `lower_bound` (нижня межа), `upper_bound` (верхня межа), `variable` (змінна інтегрування, за замовчуванням `"x"`).
